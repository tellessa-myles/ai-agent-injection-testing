# AI Agent Indirect Prompt Injection Testing

Research project testing whether tool-using AI agents can be manipulated via 
hidden instructions embedded in content they retrieve (indirect prompt injection).

## Status
In progress — Semester 1 (proposal/prototype phase)

## What this is
AI agents that can take real actions (browsing, reading files, sending messages) are being used everywhere, but almost nobody has a reliable way to test if they can be tricked by hidden instructions. This project helps close that gap between people just worrying about the risk and people actually being able to measure and fix it.
+ Gives researchers and companies a real way to check how safe their own AI agents are, instead of guessing
+ Shows which safety features (like limiting permissions or requiring human approval) actually work, based on evidence instead of assumptions
+ Adds new, credible work to a security topic that's only 1-2 years old, at a time when this is a top-ranked risk (OWASP's #1 LLM security issue)
